# Playwright Ecommerce Automation

Project structure for organizing ecommerce UI and API automation with Playwright and TypeScript.

- `src/pages`: UI page objects
- `src/api`: API clients
- `src/fixtures`: shared test fixtures
- `src/utils`: configuration, test data, and logging helpers
- `src/types`: shared API types
- `tests/ui` and `tests/api`: UI and API test suites
- `test-data`: JSON test data
- `config`: environment-specific configuration
- `allure-results`: Allure output directory

The files are structure placeholders. Add application-specific locators, API routes, and test cases before running ecommerce tests. Select an environment with `TEST_ENV=qa` or `TEST_ENV=staging` and fill in its base URLs.
